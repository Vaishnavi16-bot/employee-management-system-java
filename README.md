# Employee Management System

A simple console-based Employee Management System developed using Java.

## Features
- Add employee
- View employee details
- Search employee by ID
- Delete employee
- Menu-driven interface

## Concepts Used
- Java
- Object-Oriented Programming
- Classes and Objects
- Methods
- Scanner
- Switch Case
- Loops

## Future Improvements
- Support multiple employees
- Store employees using ArrayList
- Update employee details
- Add validation
- Connect with a database
